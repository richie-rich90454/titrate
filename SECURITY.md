# Security Policy

## Supported Versions

Titrate is pre-1.0 software. Security fixes are applied to the latest tagged release only.

| Version | Supported |
| --- | --- |
| 0.3.0-alpha (latest) | Yes |
| Earlier releases | No |

## Reporting a Vulnerability

Do not report security vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting for this repository:
https://github.com/richie-rich90454/titrate/security/advisories/new

Include as much of the following as you can:

- Affected version or commit hash.
- Component involved (compiler, bytecode VM, native backend, standard library, or build tool).
- A minimal reproduction and the exact command used.
- The impact you observed, and any suggested fix.

You should receive an acknowledgement as soon as the maintainers are able to review the report. We will keep you informed as the issue is investigated and coordinate the timing of any public disclosure with you. Please give us a reasonable opportunity to prepare a fix before disclosing the issue publicly.

## Scope

Reports about the compiler, runtime, standard library, build scripts, and the documentation site are all welcome. General bugs that are not security related belong in the issue tracker; see the bug report template.
